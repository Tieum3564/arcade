Neon Maze

Collectez les orbes, semez les sentinelles et prenez le pouvoir avec les super-orbes.

Joueur :

Déplacement — flèches, ZQSD ou WASD. Sur mobile, glissez le joystick dans une direction, puis relâchez : le déplacement continue.

Super-orbes — les gros orbes rendent les sentinelles vulnérables temporairement. Enchaînez les captures pour multiplier les points.

Objectif — videz le labyrinthe pour passer au niveau suivant. Vous avez trois vies. P ou Échap ouvre la pause.
